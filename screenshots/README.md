## 📥 How to Add More Screenshots

1. Capture screenshots from Android emulator or device:
   ```bash
   adb screenshot screenshot-name.png
   ```

2. Capture screenshots from iOS simulator or device:
   - iOS Simulator: CMD + S
   - Physical device: Volume Up + Side Button

3. Rename the file descriptively:
   - `android_device_list.jpg`
   - `ios_scanning_active.jpg`

4. Place in this folder

5. Update this README with:
   - Filename
   - Description
   - Features shown
